# chartui

A terminal charting library for Rich and Textual apps, but you probably want to use one
of these primarily open-source applications instead:

| Service                                                          | Notes                                                                                                                                                 |
| ---------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| [asciichart](https://github.com/kroitor/asciichart)              | "Nice-looking lightweight console ASCII line charts ╭┈╯ for NodeJS, browsers and terminal, no dependencies" (also ships for Python as `asciichartpy`) |
| [bashplotlib](https://github.com/glamp/bashplotlib)              | "plotting in the terminal"                                                                                                                            |
| [blessed-contrib](https://github.com/yaronn/blessed-contrib)     | "Build terminal dashboards using ascii/ansi art and javascript"                                                                                       |
| [dashing](https://github.com/FedericoCeratto/dashing)            | "Dashing is a library to quickly create terminal-based dashboards in Python"                                                                          |
| [gnuplot](http://gnuplot.info/)                                  | "a portable command-line driven graphing utility for Linux, OS/2, MS Windows, OSX, VMS, and many other platforms"                                     |
| [plotext](https://github.com/piccolomo/plotext)                  | "plotting on terminal"                                                                                                                                |
| [plotille](https://github.com/tammoippen/plotille)               | "Plot in the terminal using braille dots"                                                                                                             |
| [sparklines](https://github.com/deeplook/sparklines)             | "Text-based sparklines for the command line mimicking those of Edward Tufte"                                                                          |
| [termcharts](https://github.com/Abdur-rahmaanJ/termcharts)       | "Terminal charts with rich compatibility in mind"                                                                                                     |
| [termgraph](https://github.com/mkaz/termgraph)                   | "A Python command-line and library that draws basic graphs in the terminal"                                                                           |
| [termplotlib](https://github.com/nschloe/termplotlib)            | "Plotting on the command line"                                                                                                                        |
| [Textual](https://github.com/Textualize/textual)                 | ships a built-in `Sparkline` widget for compact numeric display, not a full charting library                                                          |
| [textual-plotext](https://github.com/Textualize/textual-plotext) | "A Textual widget wrapper library for Plotext"                                                                                                        |
| [uniplot](https://github.com/olavolav/uniplot)                   | "Lightweight plotting to the terminal. 4x resolution via Unicode"                                                                                     |
| [YouPlot](https://github.com/red-data-tools/YouPlot)             | "A command line tool that draw plots on the terminal"                                                                                                 |

Documentation can be found on [GitHub (./docs)](./docs),
[PyPi](https://pypi.org/project/chartui/), or [Hosted](https://chartui.kyleking.me/)!
